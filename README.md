Project title — e.g. "Clinic Appointment Data Cleaning — Power Query"
Short Description:
This project cleans and standardizes a real-world-style clinic appointment dataset (465+ rows) using Excel Power Query. It resolves missing gender values, inconsistent text casing, a date column mixing several formats (text, datetime, and regional variants), and a billing amount column containing multiple currencies — turning messy raw data into a consistent, analysis-ready dataset.
Dataset Overview : 
A Messy_clinic_appointment dataset with 999+ rows and columns including patient ID, appointment ID, patient name, age, gender, appointment date, booking date, doctor, and billing amount. The raw data was intentionally messy — missing values, inconsistent formats, and mixed currencies — to simulate real-world data cleaning challenges.
Problems in the raw data :
-null,error,0,1 values .
-Missing values in gender column
-Inconsistent casing (Male/male, Female/female)
-Date column mixing text, datetime, and multiple regional formats
-Billing amounts in mixed currencies (€, £, $).
Tools used: Excel, Power Query (M language), maybe Pivot Tables if you add analysis later.
